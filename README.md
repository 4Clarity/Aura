# Aura

**AI-Powered Modular Background Effect Studio**

Create stunning, professional-quality animated backgrounds with an intelligent composition framework. Aura combines node-based visual effects, layered rendering, and AI-assisted design to help anyone—from beginners to professionals—craft immersive background experiences.

## ✨ What is Aura?

Aura is a next-generation visual effects platform that transforms how you create animated backgrounds. Whether you're designing for websites, games, presentations, or digital art installations, Aura provides a modular framework where effects, layers, and nodes compose into breathtaking visuals.

## 🎯 Key Features

- **🧠 AI-Powered Onboarding** - Intelligent setup wizard that understands your vision through natural conversation
- **🎨 Modular Effect System** - Plugin architecture with particle systems, waves, flow fields, gradients, and geometric patterns
- **📐 Hierarchical Composition** - Layer-based structure with independent nodes, each fully configurable
- **⚙️ Comprehensive Controls** - Fine-tune dimensions (width, height, thickness, spacing), styling, blend modes, and effect parameters
- **🎬 Real-Time Preview** - Live canvas rendering with playback controls and timeline
- **💾 Persistent Workspace** - Auto-save compositions with full state preservation
- **🎭 Visual Effect Library** - Live previews of all available effects with animated thumbnails
- **🎨 Advanced Styling** - Opacity, blend modes (multiply, screen, overlay, etc.), shadows, and transformations
- **📱 Responsive Interface** - Collapsible panels, intuitive layer hierarchy, and professional workspace

## 🏗️ Architecture

```
Composition
  └── Layers (stackable with blend modes)
      └── Nodes (individual effect elements)
          ├── Dimensions (width, height, thickness, spacing)
          ├── Style (opacity, blend mode, rotation, scale, shadows)
          ├── Effects (modular plugin system)
          └── Media (images, videos, GIFs - framework ready)
```

## 🚀 Effect Types

- **Particle Systems** - Connected networks with physics simulation
- **Wave Generators** - Flowing sine waves with gradient colors
- **Dynamic Grids** - Animated geometric patterns with multiple shapes
- **Flow Fields** - Organic particle trails with noise-based movement
- **Animated Gradients** - Smooth color transitions with linear/radial/conic styles
